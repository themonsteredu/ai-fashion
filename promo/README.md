# 패션 아바타 스튜디오 홍보영상

- `ai-fashion-promo.mp4`: 1920×1080, 30fps, 약 53초. 배경음악과 하단 자막이 들어 있어요.
- `ai-fashion-promo.srt`: 자막 파일이에요. 유튜브 같은 곳에 자막을 따로 올릴 때 써요.
- `source/`: 영상을 다시 만들 때 쓰는 녹화·편집 스크립트예요. 앱 동작과는 상관없어요.

## 영상에 나오는 장면
1. 첫 화면: "오늘, 우리가 런웨이의 주인공"
2. 시작 화면: 포즈 미션 / 자유 체험 / 내 아바타 불러오기
3. 포즈 미션: 아바타가 시범 포즈를 보여 주고 3·2·1 카운트다운
4. 실시간 포즈 인식: POSE MATCH 게이지가 차고 "성공!"
5. 미션 결과: "총 3개 미션 중 3개 성공"
6. 45가지 포즈 미션 소개 카드
7. 자유 체험: 아바타가 움직임을 실시간으로 따라 해요
8. 사진 찍기(3초 카운트다운)와 영상 저장 방식 선택
9. VRoid로 만든 내 아바타(.vrm) 불러오기
10. 운영자 설정: 미션 개수, 합격 기준, 출제 포즈
11. 마무리 화면: start.bat 더블클릭으로 시작, 인터넷 없이 작동

## 참고
- 모든 화면은 이 폴더의 실제 앱을 제 컴퓨터(로컬)에서 실행해 녹화했어요.
- 촬영 환경에 웹캠과 사람이 없어서, **웹캠 앞 학생 역할은 3D 모델(sample_avatar.vrm)이 맡았어요.**
  앱은 그 3D 모델의 자세를 실제로 인식해 미션을 판정했어요. 영상에도 "시연: 웹캠 앞 학생 역할은 3D 모델"이라고 표시해 두었어요.
- 영상 편집을 위해 운영자 설정을 "미션 3개 중 2개 성공, 팔 포즈 3개만 출제"로 맞춰 두고 녹화했어요.
- 배경음악은 저작권 걱정 없이 쓸 수 있게 직접 만든 곡이에요(`source/music.py`).
