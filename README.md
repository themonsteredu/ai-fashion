# 패션 아바타 스튜디오 (박람회 키오스크 앱)

관람객이 3D 아바타의 옷 색상·패턴을 꾸민 뒤, 카메라 앞에서 움직이면
아바타가 실시간으로 따라 하는 체험 앱입니다.
**기본 아바타·모션·미션·퀴즈는 오프라인으로 작동합니다.** 그림을 AI 반실사로 변환할 때만 인터넷과 별도 OpenAI API 사용료가 필요합니다.

## 그림을 애니메이션 반실사 아바타로 바꾸기

1. 시작 화면의 **AI 설정**에서 운영자 비밀번호를 입력하고 본인의 OpenAI API 키를 입력합니다. ChatGPT 구독과 API 결제는 별도입니다.
2. 이미지 모델, 화질, 표현 느낌, 크기를 고릅니다. 기본값은 **GPT Image 2.5 Flare / 초안 / 애니메이션 반실사 / 빠른 전신 768 × 1024**입니다. 큰 입력은 비율을 유지해 축소한 후 전송합니다. 변환 시간은 서버와 그림에 따라 달라지며 더 큰 이미지와 높은 화질도 선택할 수 있습니다. 기존 Mini 모델은 지원하는 표준 크기만 표시합니다.
3. **그림을 반실사 아바타로**를 눌러 PNG·JPG·WebP 그림(10MB 이하)을 선택하면 변환을 시작합니다. 얼굴·나이대·머리·의상·색감을 살리고 투명 배경으로 요청합니다.
4. 원본과 결과를 비교한 뒤 **이 아바타로 사용**을 누르면 기존 모션 체험에 적용됩니다. **PNG 저장**으로 결과만 내려받을 수도 있습니다.
5. **설정 바꿔서 변환**으로 같은 원본을 다른 모델·화질로 다시 만들 수 있습니다. 최근 결과 3개를 선택해 비교합니다. 한 번에 1장만 생성하며, 다시 변환할 때마다 별도 API 사용료가 발생합니다.

| 선택 | 용도 |
|---|---|
| GPT Image 2.5 Flare | 빠르게 결과 확인 |
| GPT Image 2.5 Sunburst | 얼굴·의상 묘사를 더 정교하게 비교 |
| GPT Image 1 Mini | 저비용 시험용. 2026년 12월 1일 종료 예정이며 이후 선택지에서 자동 제외 |
| 초안 / 표준 / 정밀 | 초안으로 확인한 뒤 필요한 경우에만 화질을 높여 비용 절약 |
| 애니메이션 반실사 / 실사에 가까운 아바타 / 3D 애니메이션 | 원본 캐릭터를 유지하면서 사실감과 애니메이션 느낌 조절 |

키는 기본적으로 현재 페이지 메모리에서만 사용합니다. **이 탭에서 키 기억하기**를 선택하면 `sessionStorage`에 보관해 새로고침·60초 무조작 초기화 후에도 유지됩니다. 탭을 닫거나 **키 삭제**를 누르면 삭제됩니다. 브라우저의 탭 복원 기능이 세션을 복구할 수도 있으니 공용 기기에서는 **키 삭제**를 사용하세요. 키를 일반 설정용 `localStorage`·저장소·앱 서버에 저장하지 않습니다. 이 정적 앱은 사용자가 입력한 키와 그림을 **https://api.openai.com/v1/images/edits**로 직접 전송합니다. 개인용·운영자 관리 기기에서 사용하세요. 키는 같은 페이지의 스크립트에 접근 가능하므로 신뢰할 수 없는 스크립트를 추가하지 마세요.

AI로 완성된 결과는 **이 기기의 이 브라우저에 자동 저장**됩니다. 시작 화면의 **저장한 아바타**에서 다시 선택하거나 파일로 다운로드할 수 있습니다. 브라우저 저장 데이터를 지우거나 다른 기기·다른 브라우저로 이동하면 목록은 공유되지 않으므로, 다른 기기에서는 다운로드한 파일을 **기존 이미지 바로 불러오기**로 가져오세요. 불러올 때는 AI 요청과 API 비용이 발생하지 않습니다. 브라우저 저장이 불가능하거나 공간이 부족하면 안내가 나타나며 결과창의 PNG 저장을 이용할 수 있습니다. 이 기능을 추가하기 전에 이미 닫힌 결과는 복구할 수 없습니다.

선택한 결과는 현재 아바타 체험 동안 사용되고 기존 60초 무조작 초기화가 적용되지만, 자동 저장된 아바타는 저장 목록에 남습니다. 생성된 이미지는 2D 그림 아바타로 움직이며 3D 모델 파일을 만드는 기능은 아닙니다. 전신·정면·팔을 몸에서 살짝 뗀 그림이 움직임 인식에 적합합니다. 실제 API 변환 품질은 입력 그림과 선택한 모델에 따라 달라집니다.

**AI 설정**, **운영자 설정** 및 저장 아바타 삭제는 4자리 운영자 비밀번호를 요구합니다. 시작 화면의 버튼을 터치하거나 기존 Esc 단축키로 운영자 설정을 열 수 있습니다. 이 PIN은 정적 웹앱의 간단한 화면 잠금이며 서버 인증이나 API 키의 암호화 저장 기능은 아닙니다.

키가 없거나 인터넷을 사용할 수 없으면 비교창의 **원본 그림으로 사용**으로 기존 그림 아바타를 사용할 수 있습니다. VRM 업로드에는 AI 요청이 발생하지 않습니다. 변환 중 닫기·중지를 누르면 브라우저 요청은 취소하지만 이미 시작된 서버 처리 비용은 발생할 수 있습니다. 오류·시간 초과 시 자동 재시도하거나 더 비싼 모델로 변경하지 않습니다.

### 카메라 없이 움직임 미리보기

그림을 불러오고 **이 아바타로 사용**을 선택한 다음 시작 화면에서 **자동 동작 미리보기**를 누르면 현재 아바타가 준비된 동작을 반복합니다. 기본 아바타와 VRM 아바타도 미리 볼 수 있습니다. 이 미리보기는 카메라 연결과 추가 AI API 요청이 필요하지 않으며, 사진이나 아바타 영상을 저장할 수 있습니다.

**카메라로 따라 하기**를 선택하면 연결된 카메라에서 사람의 움직임을 인식해 아바타가 따라 합니다. 브라우저의 카메라 권한을 허용하고, 전신이 화면에 들어오도록 서 주세요. 카메라가 없거나 권한이 꺼져 있으면 화면의 **카메라 없이 자동 동작 보기**를 선택할 수 있습니다.

그림 아바타는 2D 인형처럼 움직입니다. 관절 위치를 찾은 그림은 팔·몸통 또는 전신이 움직이지만, 팔이 몸에 붙어 있거나 관절을 찾기 어려운 그림은 몸 전체가 함께 움직입니다. 머리부터 발끝까지 나온 정면 그림에서 팔·다리가 서로 떨어져 있으면 인식에 도움이 됩니다. 손가락·표정까지 독립적으로 움직이는 3D 모델이 자동으로 만들어지는 것은 아닙니다.

요금·모델 지원 기준 확인: 2026-10-28. [공식 이미지 편집 API](https://developers.openai.com/api/reference/resources/images/methods/edit), [요금](https://developers.openai.com/api/docs/pricing), [모델 종료 일정](https://developers.openai.com/api/docs/deprecations).

개발 검증: Node.js 22 이상에서 `node --test tests/*.test.mjs`. 테스트는 가짜 API 응답과 DOM 대역을 사용하므로 API 비용이 발생하지 않습니다. 실제 이미지 생성 품질은 실제 API 키로 별도 확인해야 합니다.

## 1. 실행 방법 (딱 한 번의 더블클릭)

1. 이 폴더에 있는 **`start.bat`** 파일을 더블클릭합니다.
2. 검은 창이 잠깐 뜨고, 크롬이 전체화면으로 열리면서 앱이 시작됩니다.
3. 끝낼 때는 키보드에서 **Alt + F4**를 누른 뒤, **`stop.bat`**을 더블클릭합니다.

> 처음 실행할 때 파란색 "Windows의 PC 보호" 창이 뜨면
> "추가 정보" → "실행"을 눌러 주세요.

## 2. 내 아바타로 바꾸기 (학생들 각자 아바타 사용)

**방법 A — 화면에서 바로 불러오기 (추천, 학생용)**

1. VRoid Studio에서 아바타를 만들고 **VRM 형식으로 내보내기** 합니다.
   - ⚠️ **`.vroid` 파일이 아니라 `.vrm` 파일이어야 합니다.**
     `.vroid`는 VRoid Studio 안에서만 쓰는 작업(프로젝트) 파일이라 앱에서 열리지 않습니다.
     반드시 **[내보내기] → [VRM으로 내보내기]** 로 저장한 `.vrm` 파일을 사용하세요.
   - 내보낼 때 "머티리얼(재질) 줄이기 / 합치기" 옵션은 **사용하지 마세요.**
     (합치면 상의·하의·헤어를 따로 색칠할 수 없게 됩니다)
2. 앱 첫 화면에서 **"📂 내 아바타 불러오기"** 버튼을 누르고 그 .vrm 파일을 선택합니다.
3. 바로 꾸미기 화면으로 넘어갑니다. (USB에 담아 온 파일도 그대로 선택하면 됩니다)

**방법 B — 기본 아바타 교체 (부스 대표 아바타)**

1. 내보낸 파일 이름을 **`character.vrm`** 으로 바꿉니다.
2. 이 폴더(start.bat이 있는 곳)에 넣고 앱을 다시 켭니다.
3. ⚠️ 폴더에 **`character.png`(그림 캐릭터)가 있으면 그림이 먼저 보입니다.** 3D 캐릭터를 보이게 하려면
   `character.png`와 `character.rig.json`을 다른 폴더로 옮기거나 지워 주세요.

**방법 C — 그림(PNG·JPG)으로 바꾸기 (지금 기본 캐릭터: 주황 조끼 남학생)**

- 그림을 관절대로 나눠 **종이인형처럼** 움직입니다. 팔·다리·몸통·고개가 학생 동작을 따라 해요.
  (손가락·표정·눈 깜빡임·뒤돌기는 안 돼요. 3D 캐릭터는 화면에 안 보이지만 동작 계산에 계속 쓰이니
  `character.vrm`, `sample_avatar.vrm` 파일은 지우지 마세요.)
- **좋은 그림 조건:** 배경이 투명한 PNG · 머리부터 발끝까지 전신 · 정면 · 팔을 몸에서 살짝 뗀 자세
  (흰색 같은 단색 배경도 자동으로 지워 봅니다. 복잡한 배경의 사진은 네모 카드처럼 보여요.)
- **부스 기본 캐릭터 바꾸기:** 그림 파일 이름을 `character.png`(소문자)로 바꿔 기존 파일을 덮어쓰고 앱을 다시 켭니다.
  관절 위치는 앱이 자동으로 찾아요. JPG 그림이면 `character.jpg`로 바꾸고, **기존 `character.png`는 꼭 지우거나
  다른 폴더로 옮겨 주세요** (둘 다 있으면 `character.png`가 먼저 보여요).
  (예전 그림의 관절 파일 `character.rig.json`이 남아 있어도 자동으로 무시돼요. 지워도 괜찮아요.)
  - ⚠️ 윈도우에서 확장자가 숨겨져 있으면 이름이 `character.png.png`가 될 수 있어요.
    파일 탐색기 [보기] → [파일 확장명]을 켜고 이름을 확인해 주세요.
- **화면에서 바로 불러오기:** 첫 화면 "내 아바타 불러오기"에서 PNG·JPG 그림을 고르면 됩니다.
  팔·다리 위치를 찾지 못한 그림이나 팔이 몸에 붙어 있는 그림은 그림 전체가 한 덩어리로(옆걸음·앉기·기울이기) 움직여요.
  불러온 아바타는 그 관람객 체험 동안만 쓰이고, **60초 동안 조작이 없으면 기본 캐릭터로 돌아가요.**
- 학생 사진을 쓸 때는 본인(보호자) 동의를 받아 주세요. 다른 사이트에서 만든 그림은 그 사이트의 이용 약관도 확인해 주세요.

## 3. 화면 흐름

| 화면 | 내용 |
|---|---|
| 시작 | "포즈 미션 시작" · "수학 퀴즈" · "자유 체험" 버튼 + "내 아바타 불러오기" 버튼. 60초 동안 아무도 화면 앞에 없고 조작하지 않으면 자동으로 이 화면으로 돌아옵니다. |
| 아바타 꾸미기 | 부위 선택 → 12색 팔레트 + 패턴(단색/줄무늬/도트/체크). 아바타를 드래그하면 돌려볼 수 있습니다. |
| 모션 체험 | 팔·손가락(브이✌)·고개·몸통·다리·앉기까지 따라 합니다(그림 캐릭터는 손가락·표정 제외). "사진 찍기"(3초 후 캡처), "영상 찍기"(최대 30초 녹화) 모두 아바타 화면만 저장됩니다(다운로드 폴더). |

- 사진과 "아바타만" 영상에는 웹캠 화면이 포함되지 않습니다.
- "아바타 + 내 모습" 영상은 **본인 모습이 함께 저장**되므로,
  촬영 대상(학생·관람객)의 동의를 받고 사용해 주세요.
- 다리·앉기까지 인식하려면 **전신이 카메라에 나오도록** 2~3걸음 뒤로 물러서면 좋습니다.
  (하반신이 화면에 안 보이면 다리는 자동으로 차렷 자세를 유지합니다)

### 포즈 미션 (총 55가지 포즈)

- "포즈 미션 시작"을 누르면 포즈가 한 판에 5개씩 무작위로 나옵니다 (운영자 설정에서 개수 변경 가능).
- 분류: 팔 · 방향 · 귀여운 · 전신 · 동작 · **모델(패션 모델 포즈 10가지)**
- 패션 모델 포즈: 한 손 허리 모델, 머리 쓸어넘기기, 옷깃 세우기, 시크한 팔짱, 어깨 가방 메기,
  S라인 포즈, 스타 포즈, 다리 꼬고 서기, 피날레 인사, 고개 돌려 시크하게
  - 모델 포즈는 다른 포즈보다 더 자주 나오도록 되어 있어요.
  - "시크한 팔짱", "피날레 인사", "고개 돌려 시크하게"는 **테스트용(EXPERIMENTAL)** 이라 처음엔 꺼져 있어요.
    운영자 설정에서 "테스트" 버튼으로 학생과 직접 해 보고 잘 되면 체크해서 켜 주세요
    ("STABLE 포즈만 출제" 체크도 해제해야 나와요).
  - "스타 포즈", "다리 꼬고 서기"는 전신이 카메라에 보여야 합니다.
- 잘 안 되는 포즈가 있으면 키보드 **Esc** → 운영자 설정의 포즈 목록에서 체크를 끄면 출제되지 않아요.
- 포즈를 **약 0.4초** 유지하면 성공이에요. 잠깐 흔들려도 처음부터 다시 하지 않고 게이지가 천천히 줄어들어요.
  더 길게/짧게 하고 싶으면 Esc → "유지시간(ms)"을 바꾸세요 (1000 = 1초).

### 수학 퀴즈 (몸으로 푸는 2지선다)

화면 왼쪽·오른쪽에 답이 하나씩 나오고, **정답이 있는 쪽 손을 번쩍 들면** 답이 골라집니다.
(화면은 거울처럼 보이므로 왼쪽 답 = 왼손, 오른쪽 답 = 오른손)

1. 시작 화면에서 **"수학 퀴즈"** 를 누릅니다.
2. 단계를 고릅니다 (화면을 터치하거나 마우스로 클릭).
   | 단계 | 대상 | 나오는 문제 |
   |---|---|---|
   | 🌱 쉬움 | 초등 1~2학년 | 덧셈·뺄셈, 더 큰 수 고르기, 수 규칙(2, 4, 6, 8, ?), 맞는 식 O/X, 도형·시간 상식 |
   | 🔥 보통 | 초등 3~6학년 | 구구단, 나눗셈, 받아올림 덧셈, 계산 순서(곱셈 먼저), 분수 크기·덧셈, 소수 덧셈, 단위 |
   | 🚀 어려움 | 중학생 | 음수 곱셈·덧셈, 일차방정식, 거듭제곱, 제곱근, 분배법칙, 동류항, 도형의 각 |
3. 두세 걸음 뒤로 서면 아바타가 손 드는 법을 보여주고, **연습 문제 1개**(점수에 안 들어감) 후 본 문제가 시작됩니다.
4. 손을 **약 1초 동안** 들고 있으면 답으로 인정돼요. 답 카드가 아래에서부터 파랗게 차오릅니다.
   - 새 문제가 나오면 **손을 한 번 내렸다가** 다시 들어야 해요 (실수로 바로 답이 골라지는 것 방지).
   - 양손을 다 들면 "한 손만 들어요!" 안내가 나오고 답이 골라지지 않아요.
   - 사람이 화면에서 사라지면 타이머가 멈춰요 (불이익 없음).
5. 답을 고르면 정답 카드가 초록색으로 표시되고, **풀이 한 줄**이 나오고, 아바타가 기뻐하거나 놀라는 동작을 해요.
6. 결과 화면에서 문제별 정답·오답을 다시 볼 수 있고, 기준 이상 맞히면 **"수학 천재 인증! 선물을 받아가세요!"** 가 나와요.
   - "📷 기념사진" · "다른 단계 도전" · "다음 참가자" 버튼이 있어요.
- 문제는 매번 새로 만들어지므로 같은 문제가 반복되지 않아요. 오답 보기는 학생들이 자주 하는 실수(받아올림 빠뜨림, 곱셈 먼저 안 함 등)로 만들어져 있어요.
- 진행 중 왼쪽 위 **"← 처음으로"** 를 누르면 언제든 시작 화면으로 돌아가요.

**운영자 설정 (키보드 Esc)** — "수학 퀴즈 설정" 칸에서 바꾼 뒤 "설정 저장"을 누르세요.

| 항목 | 기본값 | 설명 |
|---|---|---|
| 문제 개수 | 5 | 한 판에 나오는 문제 수 (1~10) |
| 선물 기준 정답 수 | 3 | 이만큼 맞히면 "선물을 받아가세요!" |
| 문제당 제한시간(초) | 10 | 이 시간 안에 손을 들어야 해요 |
| 손 유지시간(ms) | 800 | 손을 이만큼(1000 = 1초) 들고 있어야 답으로 인정. 실수로 골라지면 늘리고, 답답하면 줄이세요 |
| 시작 전 연습 문제 | 켬 | 줄이 길 때는 꺼서 시간을 줄일 수 있어요 |

- 퀴즈 중 단축키: **← / →** 왼쪽·오른쪽 답 고르기 (손 인식이 어려운 학생용) · **N** 문제 건너뛰기
- 답 카드를 손가락으로 터치하거나 마우스로 클릭해도 답을 고를 수 있어요.
- Esc 운영자 설정은 이제 시작 화면에서도 열려요. (포즈 "테스트"·미션 운영 버튼은 포즈 미션 중에만 보여요)

## 4. 오프라인(인터넷 없이) 작동 확인하는 방법

1. 노트북의 와이파이를 끕니다.
   (화면 오른쪽 아래 지구본/와이파이 아이콘 클릭 → 와이파이 끄기, 비행기 모드도 가능)
2. `start.bat`을 더블클릭해서 앱을 켭니다.
3. 시작 → 포즈 미션 / 수학 퀴즈 / 자유 체험 → 사진 찍기까지 전부 눌러 봅니다.
4. 모든 기능이 그대로 되면 합격입니다.
   필요한 파일(3D 라이브러리, 모션 인식 모델)이 전부 이 폴더 안에 들어 있기 때문입니다.

## 5. 문제가 생겼을 때

| 증상 | 해결 방법 |
|---|---|
| 크롬이 안 열린다 | 크롬이 설치되어 있는지 확인 후 다시 `start.bat` 실행 |
| "카메라를 사용할 수 없어요" | 웹캠 케이블 연결 확인 → 앱 종료(`stop.bat`) 후 다시 `start.bat` |
| 아바타가 안 나온다 | `character.vrm` 파일 이름이 정확한지 확인 (대소문자 무관, 확장자 .vrm) |
| 그림 캐릭터의 팔·다리가 이상하게 늘어난다 | 그림을 바꿨는데 예전 `character.rig.json`이 남아 있는 경우입니다. 그 파일을 지우고 다시 켜세요 |
| 3D 캐릭터로 돌아가고 싶다 | `character.png`와 `character.rig.json`을 지우거나 다른 폴더로 옮기고 다시 켜세요 |
| "프로젝트 파일(.vroid)이에요" 라고 뜬다 | VRoid Studio 작업 파일을 고른 경우입니다. VRoid Studio에서 [내보내기] → [VRM으로 내보내기]로 저장한 `.vrm` 파일을 다시 선택하세요 |
| "VRM 파일이 아니에요" 라고 뜬다 | 확장자만 .vrm이고 내용이 다른 파일입니다. VRoid Studio에서 다시 내보내 주세요 |
| 화면이 멈췄다 | Alt+F4로 닫고 `stop.bat` → `start.bat` 다시 실행 |
| 색이 일부만 바뀐다 | VRM 내보내기 시 머티리얼 합치기 옵션을 껐는지 확인 |

## 6. 폴더 구성 (참고용 — 지우면 안 되는 것들)

- `start.bat` / `stop.bat` — 켜기 / 끄기
- `serve.ps1` — 앱을 띄워 주는 내부 프로그램 (건드리지 않기)
- `index.html`, `css/`, `js/` — 앱 화면과 동작
- `lib/` — 3D·모션 인식 라이브러리 (전부 로컬 파일, 인터넷 불필요)
- `models/` — 모션 인식 모델 파일
- `character.vrm` — 내 아바타 (직접 넣는 파일)
- `sample_avatar.vrm` — 테스트용 아바타
- `character.png` — 그림 캐릭터 (있으면 3D 대신 이 그림이 보여요)
- `character.rig.json` — 그림 캐릭터의 관절 위치 (그림을 바꾸면 지우기)

메모장으로 열어 조금씩 바꿀 수 있습니다. 각 숫자 옆에 한국어 설명이 있습니다.
