# 그림 아바타·포즈 미션 회귀 검증 (2026-10-28)

검증 기준: 기본 브랜치 `claude/fashion-3d-avatar-motion-msqviw`, `369b278`.
PR #3의 그림 관절 추종, PR #5의 화면 맞춤·400ms 유지, 이후 자동 미리보기 변경을 포함한다.

## 발견해서 수정한 오류

1. 낮은 관절 visibility에도 추정 좌표를 그대로 채점했다. 양팔 위 자세의 visibility를 0.1로 내려도 confidence=1로 통과했다. 수평 어깨도 낮은 visibility에서 lean_left/right confidence≈0.73으로 통과했다. 이제 보이지 않거나 없는 필수 조건 관절은 점수를 얻지 못하고 분모는 유지한다. 정상 visibility에서의 기존 점수·통과 기준은 그대로다.
2. 준비 카운트다운이 모바일에서 얼굴·팔을 가렸다. 데스크톱에서도 양팔을 벌렸을 때 겹칠 수 있었다. 카운트다운과 ‘시작!’을 상단 여백에 작게 배치했다. 그림의 스키닝된 전체 메시 경계와 두 카운트다운 상태의 사각형이 겹치지 않는지 검사한다.

추가 리뷰 검증: `point_up`·`chin_rest`는 보이는 한 손만으로 성공할 수 있도록 후보별로 신뢰도를 확인한다. 좌우 각각 반대 손 가림, 정답 손 가림, 양손 가림, 코 가림을 검사했다.

## 자동 검증 범위

- `npm test`: 54개 테스트 통과. 신규 11개는 양팔/왼팔/오른팔 올리기, 좌우 기울이기의 정답·중립·반대 자세·낮은 신뢰도, 400ms 유지, 200ms 흔들림 후 복귀, 긴 이탈 후 진행 감소, 오답 타임아웃을 확인한다.
- `npm run test:avatar`: 실제 페이지를 열고 기본 VRM 및 character.png의 full 리그를 로드한다. 카메라/MediaPipe 출력 경계만 합성 스냅샷과 시범 관절 드라이버로 바꾼다. 실제 main 렌더 루프, VRM 업데이트, Puppet 스키닝, MissionUI, MissionJudge, 카메라 맞춤은 실행한다.
- 각 화면에서 카운트다운 → 오답 → 짧은 정답 → 흔들림 → 복귀 → 성공 → 결과 화면까지 실행하고, 그림 손 위치의 변화와 성공 기록이 정확히 1회인지 확인한다.
- 양팔 올리기, 왼팔/오른팔 올리기, 양팔 벌리기, 좌우 기울이기 6종의 그림 메시 전체 경계를 검사한다. 화면 밖으로 나가거나 하단 카드·카운트다운에 겹치면 실패한다. 페이지 JavaScript 오류도 실패 처리한다.

| 분류 | 화면 크기 |
|---|---|
| 데스크톱 | 1920×1080, 1366×768 |
| 태블릿 | 1024×768, 768×1024 |
| 모바일 | 390×844, 360×740 |

결과 JSON과 스크린샷은 `test-results/`에 생성된다. PR CI가 자동 실행하며 결과를 Actions artifact로 보관한다.

## 재현

Node 22 이상에서:

```sh
npm ci
npx playwright install --with-deps chromium
npm test
npm run test:avatar
```

시스템 Chromium은 `CHROMIUM_PATH`로 지정할 수 있다. 외부 폰트 접근이 제한된 환경은 원래 CSS가 쓰는 S-CoreDream-3Light/5Medium/7ExtraBold/9Black.woff를 폴더에 준비하고 `FONT_DIR`를 지정한다. 테스트는 이 폰트들을 로드한 후 화면을 검사한다. 유료 API·학생 영상·실제 카메라를 사용하지 않는다.

## 실제 웹캠에서 남은 확인

이 테스트는 합성 추적 출력과 관절 드라이버를 사용하므로 MediaPipe 영상 추론, 실제 Motion.applyToVRM의 사람→VRM 리타게팅, 카메라 권한/기기 연결, 캘리브레이션, 조명·거리·가림·좌우 반전의 실제 인식 정확도를 증명하지 않는다. 수업 기기에서 팔 올리기·기울이기·흔들림 복귀를 직접 확인해야 한다. 임의 업로드 그림의 upper/standee 리그 및 모든 포즈의 정확도도 이번 기본 full 리그 검증 범위 밖이다.

## 클로드 작업 확인

`claude/promo-video`는 PR #5로 병합된 이력이다. 기본 브랜치에 없는 유일한 원격 브랜치 변경은 `claude/text-line-break-change-6snnda`의 `7371fbf`(시작 화면 한글 줄바꿈 CSS 14줄)다. 미션/그림 동작의 미완성 코드는 아니며 이번 수정에 합치지 않았다. 다른 환경에 저장되지 않은 클로드 세션의 로컬 작업은 GitHub에서 확인할 수 없다.
