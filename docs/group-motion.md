# 모둠 3D 동작 만들기

시작 화면의 **모둠 3D 동작 만들기** 또는 `/group-motion.html`에서 엽니다.
기존 포즈 미션, 수학 퀴즈, 체육 릴레이, 2D 아바타 기능은 유지합니다.

## 수업 흐름

1. 모둠별 패드/노트북에서 모둠 이름, 활동, 남녀 아바타, 녹화 길이(5~20초)를 선택합니다.
2. 카메라를 켜고 머리와 양쪽 발끝이 보이도록 정면에 서서 체형을 맞춥니다.
3. 학생이 한 명씩 3초 카운트다운 후 녹화합니다. 각 영상은 바로 확인하고 다시 녹화할 수 있습니다.
4. 네 영상이 준비되면 `모둠 영상 만들기`를 누릅니다. 1→2→3→4 순서로 실제 영상을 재인코딩합니다.
5. 각 영상 또는 전체 영상을 기기로 저장/공유합니다. 지원되는 브라우저에서는 MP4, 그 외에는 WebM으로 저장합니다.

카메라 얼굴 영상과 소리는 녹화하지 않습니다. 아바타 화면만 녹화하며, 추적과 저장은 기기 안에서 실행합니다.
IndexedDB에 학생별 영상과 전체 영상을 보관하지만, 브라우저 데이터 삭제나 저장공간 정리로 지워질 수 있으므로 수업 종료 전에 파일로 저장해야 합니다.
자동 저장이 실패하면 해당 안내를 표시하고 다운로드할 수 있게 영상은 메모리에 유지합니다.
네 영상 중 하나를 다시 녹화하면 이전 합본은 무효화합니다. 새로고침 시에도 원본 revision 순서와 일치하는 합본만 복원합니다.

## 아바타와 추적

- `assets/kids/boy.glb`, `girl.glb`: 직접 작성한 Blender 도형과 스킨 가중치로 만든 시제품. 각각 52개 관절과 손가락 관절을 포함합니다. 이번 작업에 유료 이미지/3D 생성 API 호출은 없습니다.
- `tools/build-kid-avatars.py`: 제작 원본. Blender의 새 장면에서 `blender --background --factory-startup --python tools/build-kid-avatars.py`로 재생성합니다. `boy_direct.glb`, `girl_direct.glb`를 해당 assets 경로로 복사합니다. 스크립트는 열려 있는 장면을 지우므로 기존 작업 중인 Blender 장면에서 실행하지 않습니다.
- `kid-rig.js`: GLB의 실제 관절 축과 기존 VRM 정규 관절 축 사이의 변환. 부모의 회전을 제거해 중복 회전/목 찌그러짐을 막습니다.
- `motion.js`: `meta.spatialRig`가 있는 새 아바타에서만 3D 월드 좌표, 측면 몸통 회전, 관찰한 다리 방향, 앉기 높이를 사용합니다. 기존 아바타의 보정은 유지합니다.
- 그룹 페이지는 표정 인식을 요청하지 않아 패드의 연산 부담을 줄입니다. 손/몸 인식은 기존 로컬 MediaPipe 모델을 사용합니다.
- 보기의 정면/측면/뒷면은 **아바타를 바라보는 카메라 방향**입니다. 촬영 카메라가 여러 대가 되는 기능은 아닙니다.
- 카메라 없이 확인하는 시범 동작은 실제 추적과 구분되며 녹화 영상에도 `시범 동작`을 표시합니다.

## 확인 범위와 한계

- 자동 검사: 남녀 실제 GLB 로드, 팔 동작 중 머리 위치 유지, 손가락 관절 존재, 앉기, 유한한 변형 좌표, 합본 유효성, 녹화 형식 선택 및 캡처 트랙 해제.
- 합성 랜드마크 통합 검사: 추적→필터→체형 보정→새 관절 구조까지 연결하여 측면 회전과 앉기를 검사합니다. 이 검사는 실제 카메라 인식률을 입증하지 않습니다.
- 단일 카메라에서 몸 뒤로 가려진 손/팔/다리, 빠른 발차기와 손가락은 추정이 흔들릴 수 있습니다. 실제 수업 기기와 공간에서 별도 확인이 필요합니다.
- 바닥 높이는 다리 자세를 기준으로 보정합니다. 공중 점프 높이, 바닥과의 접촉, 앉은 의자와의 충돌을 정밀하게 재구성하지 않습니다. 줄이나 도구를 3D로 복원하지 않습니다.
- 정면에서 체형을 맞춘 다음 동작합니다. 촬영 거리나 줌을 바꾸면 자세를 다시 맞춥니다. 줌은 해당 카메라가 지원할 때만 표시합니다.
- 재녹화/이어 붙이기 중에는 다른 학생 선택을 잠급니다. 화면을 끄거나 다른 앱으로 전환하면 녹화는 종료되고, 합본 작업은 취소됩니다. 기존 학생 영상은 유지됩니다.
- 현재 디자인은 동작 확인용 시제품입니다. 최종 캐릭터 외형 교체 시 같은 골격 규칙을 유지하고 다시 변형 검사를 합니다.

검사 명령: `npm test` (Node 22.15 이상).
